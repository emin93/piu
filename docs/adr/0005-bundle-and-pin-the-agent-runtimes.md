# Bundle and pin the agent runtimes

Each application release will bundle and manage tested versions of Node, Pi, CPython, oMLX, and MLX and name one exact Hugging Face revision for the Qwen target and MTP drafter. Più accepts the roughly 0.8 GB compressed runtime cost of current oMLX packaging because an atomic self-contained release is simpler than a second signed runtime download and recovery lifecycle. Development and release preparation start from the latest stable compatible versions available at that time, including Tauri, React, Pi, oMLX, MLX, and supporting libraries. Più then pins the selected dependency graph and runtime assets rather than resolving floating `latest` versions at build or runtime. The application will not execute arbitrary system-installed versions or check for independent model updates. This keeps the stack current at selection time while making the Pi protocol, provider catalog, extension behavior, MLX dependencies, and Qwen MTP path reproducible as one tested Più release.
