# Isolate Più runtime state

Più will provide a self-contained agent environment by giving its bundled Pi runtime application-owned configuration and session directories. It will not read, import, modify, or synchronize the `~/.pi/agent` state of a separately installed Pi CLI. Pi's default skill discovery also reaches `~/.agents/skills`, so Più will start the pinned runtime with default skill loading disabled and pass only explicit Più-owned global skill paths and trusted project skill paths beneath the chat worktree. It will not rewrite `HOME`, because tools must continue to see the user's real home directory. Project-owned context and resources remain available from the chat worktree, but every global model route, credential, skill, extension, package, setting, and session shown in Più belongs to Più.
