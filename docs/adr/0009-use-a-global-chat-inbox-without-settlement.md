# Use a global chat inbox without settlement

Più will show every unmerged chat from every opened project in one stable newest-created-first inbox, with an optional project filter and transient agent-activity indicators on each row. It will not copy T3 Code's Pinned, Snoozed, Settled, automatic-inactivity, manual-ordering, or legacy-sidebar states in the first release. A finished agent turn does not complete or reclassify the chat. Merging its pull request automatically archives the chat into a collapsible, searchable, read-only Merged history. An unwanted unmerged chat is permanently deleted rather than manually archived. Search covers chat title, project, branch, and pull-request number without indexing transcripts. This preserves a useful cross-project work queue without introducing a separate lifecycle.
