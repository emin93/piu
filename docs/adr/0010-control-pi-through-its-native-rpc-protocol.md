# Control Pi through its native RPC protocol

Più will launch one bundled Pi process in RPC mode for each active chat and communicate through Pi's native JSONL standard-input and standard-output protocol. A narrow host module owns process supervision, request correlation, event translation, steering, model and reasoning changes, abort, session restoration, and shutdown. A small bundled launcher constructs the child with Pi's public session APIs and hands it to Pi's official RPC runner so Più can inject its Keychain-backed credential store without copying Pi's CLI bootstrap. Pi's session journal remains the conversation source of truth. This preserves Pi's project and application-owned resource discovery, `openai-codex` subscription authentication, current model metadata, and native semantics without adding an experimental HarnessAgent, sandbox, VFS mirror, or second lifecycle abstraction. AI Elements remains a frontend presentation dependency and does not participate in the agent transport.
