# Create one worktree for every chat

Sending the first message in a chat will fetch the remote and automatically create an isolated Git worktree and local branch directly from the updated `origin/main` reference. It will not use the user's current checkout and will not offer a base-branch selector. Più will keep worktrees in its Application Support directory instead of placing them beside the source repository. The branch will be generated from the first prompt as `agent/<short-chat-id>-<prompt-slug>`. This avoids concurrent agents sharing a checkout and gives each chat its own branch and diff. Multiple chats may run concurrently. If the repository contains an executable `.piu/setup.sh`, Più runs it directly from the new worktree before starting the agent, with `PIU_PROJECT_ROOT` and `PIU_WORKTREE_ROOT` available. A setup failure leaves the worktree and log available for Retry or Open Terminal. When the chat's pull request is merged, Più automatically archives the conversation into read-only Merged history, removes its worktree, and deletes its local branch while leaving remote-branch deletion to GitHub repository policy. Deleting an unmerged chat is permanent and never closes its pull request or deletes its remote branch.
