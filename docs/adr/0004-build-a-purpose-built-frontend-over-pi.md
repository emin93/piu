# Build a purpose-built frontend over Pi

The product will use a purpose-built macOS frontend built with React and AI Elements over Pi's native JSONL RPC protocol. Existing community Pi frontends are not the product foundation. AI Elements supplies editable presentation components, while Pi remains the only agent runtime and owns the model loop, tools, skills, extensions, and sessions. Più will not use the experimental AI SDK Pi Harness adapter: its HarnessAgent and sandbox abstractions add an unnecessary agent layer for a local Tauri application, while its current resource discovery, authentication, version, and reasoning-level constraints conflict with Più's requirements. Messages sent during an active run always use Pi's steering behavior. Completed successful tool calls collapse automatically; running and failed calls remain expanded, and reasoning is collapsed but inspectable. Sent turns are immutable and the first release has no regenerate or conversation-fork behavior. Stop aborts only the active turn and owned tool process. A failed turn remains visible and is never replayed automatically.
